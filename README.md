# HabitApp (制作途中)
## 概要
タスクや習慣、メモなど頭の中を整理できるアプリを目指しています。

個人製作２作目のアプリです。<br>
1作目で制作したタスクアプリ(Java)をもとに、機能の改善・拡張を行うとともに、
Flutterによるアプリ開発の学習を目的として制作しています。



## 目的
- プログラミングの学習
- 大学生活でタスク管理アプリとして使いたい

## 使用技術
- Flutter
- Dart

## AIの利用について
本アプリ制作ではChatGPTを開発支援ツールとして利用しています。

開発当初は、Flutter・Dartのコードを確認・理解しながら実装を進めていました。<br>
その後、実装する機能やコード量が増えたため、現在はAIによるコード生成や修正も活用しながら開発を進めています。

AIは主に、機能の実装、既存コードの修正、エラーの原因調査、UIや機能の検討などに利用しています。

AIによって生成されたコードを含むため、今後は実際にアプリを使用・改善しながらコードを読み返し、Flutter・Dartやアプリ開発への理解を深めていく予定です。
